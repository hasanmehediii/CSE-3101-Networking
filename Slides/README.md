# Lecture Slides

This directory contains the lecture slides for the CSE-3101 Networking course, covering chapters 1 through 8. The slides are available in both PowerPoint (`.pptx`) and PDF formats.

## PowerPoint Slides

- **`Chapter_1_v8.1.pptx`**: Chapter 1 - Computer Networks and the Internet
- **`Chapter_2_v8.1.pptx`**: Chapter 2 - Application Layer
- **`Chapter_3_v8.0.pptx`**: Chapter 3 - Transport Layer
- **`Chapter_4_v8.0.pptx`**: Chapter 4 - The Network Layer: Data Plane
- **`Chapter_5_v8.0.pptx`**: Chapter 5 - The Network Layer: Control Plane
- **`Chapter_6_v8.0.pptx`**: Chapter 6 - The Link Layer and LANs
- **`Chapter_7_v8.0.pptx`**: Chapter 7 - Wireless and Mobile Networks
- **`Chapter_8_v8.0.pptx`**: Chapter 8 - Security in Computer Networks
