# Networking Lab-6: SMTP Server Configuration with Cisco Packet Tracer

This lab shifts from software-based analysis to network simulation using Cisco Packet Tracer. The primary objective is to build a simulated network and configure a Simple Mail Transfer Protocol (SMTP) server to enable email communication between clients.

## Key Concepts

### Cisco Packet Tracer
Cisco Packet Tracer is a powerful network simulation tool that allows students to experiment with network behavior and ask "what if" questions. It provides a realistic simulation of functional networks.

### SMTP (Simple Mail Transfer Protocol)
SMTP is the standard protocol for sending email messages from a mail client to a mail server, and for routing email between mail servers.

### Network Configuration
This lab involves:
- **Building a network topology:** Placing and connecting devices like PCs, servers, switches, and routers in the Packet Tracer workspace.
- **IP addressing:** Assigning IP addresses to all devices in the network.
- **Configuring an SMTP server:** Setting up the email service on a server device, creating user accounts, and associating them with email addresses.
- **Configuring email clients:** Setting up email clients on PCs to send and receive emails through the configured SMTP server.
