# Networking Lab-8: TCP Congestion Control

This lab explores the mechanisms of TCP congestion control, a critical aspect of network performance. The focus is on understanding and comparing different congestion control algorithms, specifically TCP Tahoe and TCP Reno.

## Key Concepts

### TCP Congestion Control
Congestion control in TCP is the mechanism by which a sender can regulate its sending rate to avoid overwhelming the network. This is crucial for maintaining network stability and fairness.

### Congestion Control Algorithms
- **TCP Tahoe:** An early version of TCP congestion control. It uses a simple approach: upon packet loss (detected by a timeout), the congestion window is reset to 1, and it enters a "slow start" phase.
- **TCP Reno:** An improvement over Tahoe. It introduces "fast retransmit" and "fast recovery." Upon receiving three duplicate ACKs, it halves the congestion window and retransmits the lost packet without waiting for a timeout, making it more efficient.
