# Template Files

This directory contains template files for various labs in the CSE-3101 Networking course. These files serve as a starting point for students to complete their assignments.

## Java Templates

- **`Client1.java`**: A template for a client application.
- **`Client2.java`**: Another template for a client application.
- **`Client3.java`**: A third template for a client application.
- **`Server.java`**: A template for a server application.

These Java files provide a basic structure for socket programming, which students can build upon to implement the specific requirements of labs like Lab 3 and Lab 4.
