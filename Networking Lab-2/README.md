# Networking Lab-2: HTTP Packet Analysis with Wireshark

This lab is the first exploration into packet analysis using Wireshark, with a specific focus on the Hypertext Transfer Protocol (HTTP). The goal is to understand the structure of HTTP requests and responses by capturing and analyzing network traffic.

## Key Concepts

### Wireshark
Wireshark is a powerful network protocol analyzer that allows you to capture and interactively browse the traffic running on a computer network. It is the de facto standard for network analysis.

### HTTP Protocol
HTTP is the foundation of data communication for the World Wide Web. It is a request-response protocol in the client-server computing model. In this lab, we analyze:
- **HTTP GET and POST requests:** The two most common HTTP methods.
- **HTTP Headers:** Metadata sent with a request or response, such as user-agent, content type, and cookies.
- **HTTP Status Codes:** Codes like `200 OK`, `404 Not Found`, and `301 Moved Permanently` that indicate the status of a request.
