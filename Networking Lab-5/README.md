# Networking Lab-5: DNS Packet Analysis with Wireshark

This lab focuses on the Domain Name System (DNS), a critical component of the internet's infrastructure. Using Wireshark, we will capture and analyze DNS traffic to understand how domain names are resolved into IP addresses.

## Key Concepts

### Domain Name System (DNS)
DNS is a hierarchical and decentralized naming system for computers, services, or other resources connected to the Internet or a private network. It translates human-readable domain names (like `www.google.com`) into machine-readable IP addresses (like `172.217.16.196`).

### DNS Queries and Responses
- **DNS Query:** A request sent from a client (or a local DNS resolver) to a DNS server to resolve a domain name.
- **DNS Response:** The answer sent by the DNS server, containing the IP address or other requested information.
- **Record Types:** DNS uses various record types, such as `A` (for IPv4 addresses), `AAAA` (for IPv6 addresses), `CNAME` (for canonical names/aliases), and `MX` (for mail exchange servers).

## Lab Activities

The lab involves using Wireshark to capture DNS traffic generated by a web browser or command-line tools like `nslookup`. By analyzing the captured packets, we can observe:
- The structure of DNS query and response messages.
- The different types of DNS records.
- The use of UDP for DNS communication.
- The hierarchical nature of DNS lookups.
