# CSE-3101-Networking Lab

This repository contains the lab work for the CSE-3101 Networking course. Each directory corresponds to a specific lab, covering fundamental concepts of computer networking.

## Labs Overview

*   **[Networking Lab-1](#networking-lab-1):** Introduction to basic network troubleshooting tools like `ping`, `traceroute`, and `nslookup`.
*   **[Networking Lab-2](#networking-lab-2):** Packet analysis with Wireshark, focusing on the HTTP protocol.
*   **[Networking Lab-3](#networking-lab-3):** Implementation of a client-server application using socket programming.
*   **[Networking Lab-4](#networking-lab-4):** File transfer implementation using socket programming and handling HTTP GET/POST requests.
*   **[Networking Lab-5](#networking-lab-5):** DNS packet analysis using Wireshark.
*   **[Networking Lab-6](#networking-lab-6):** Configuration of a network with an SMTP server using Cisco Packet Tracer.
*   **[Networking Lab-7](#networking-lab-7):** In-depth packet analysis of the TCP layer using Wireshark.
*   **[Networking Lab-8](#networking-lab-8):** Study of TCP congestion control algorithms like Tahoe and Reno.

---

## Networking Lab-1

This lab introduces fundamental network diagnostic tools.
- **`ping`:** Used to test the reachability of a host on an Internet Protocol (IP) network.
- **`traceroute`:** A network diagnostic tool for displaying the route (path) and measuring transit delays of packets across an IP network.
- **`nslookup`:** A tool for querying the Domain Name System (DNS) to obtain domain name or IP address mapping, or other DNS records.

## Networking Lab-2

This lab focuses on analyzing HTTP traffic using Wireshark. Students learn to capture and inspect HTTP packets to understand the protocol's request-response structure, headers, and data transmission.

## Networking Lab-3

A practical introduction to socket programming. This lab involves creating a simple client-server application where the client sends a message to the server, and the server responds.

## Networking Lab-4

Building upon socket programming concepts, this lab implements a file transfer mechanism between a client and a server. It also covers the basics of handling HTTP GET and POST requests.

## Networking Lab-5

This lab delves into the Domain Name System (DNS). Using Wireshark, students analyze DNS queries and responses to understand how domain names are resolved to IP addresses.

## Networking Lab-6

This lab involves using Cisco Packet Tracer to simulate a network environment. The main objective is to set up and configure an SMTP (Simple Mail Transfer Protocol) server for email communication.

## Networking Lab-7

A deeper dive into the TCP protocol. Wireshark is used to capture and analyze TCP segments, focusing on connection establishment (three-way handshake), data transfer, and connection termination.

## Networking Lab-8

This lab explores TCP congestion control. Students analyze the behavior of different congestion control algorithms, such as Tahoe and Reno, by examining packet traces and performance logs.
